# Ernesto v14.3 — Workspace UX

## Objective

Turn the existing Ernesto tutor into a clearer, more coherent working environment without changing the validated v14.2 access-control architecture.

## Phase 1 — visual foundation

- EPPPN olive, warm ivory, terracotta and ochre visual system;
- dossier colour remains a persistent visual identity;
- quieter cards, borders and shadows;
- clearer Action / Analyse controls;
- answer actions moved visually after the answer;
- checklist reframed as “À faire maintenant”;
- cleaner desktop and mobile composer.

## Next phases

1. semantic Action / Analyse response structure;
2. Approfondir and Plan d’action answer actions;
3. smarter copy actions for protocols, actions and tables;
4. compact context summary;
5. stronger dossier memory and objective handling;
6. component extraction from the large page component where this reduces risk.

## Guardrails

- preserve v14.2 invitation and immutable email/user binding;
- preserve existing projects, dictation, image upload and graphs;
- avoid large all-at-once refactors;
- validate each phase on Vercel Preview before merging.
